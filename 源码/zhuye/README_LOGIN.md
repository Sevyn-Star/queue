# 登录功能使用说明

## 功能概述
本小程序实现了完整的手机号登录功能，包括用户注册、登录、信息管理等。

## 主要功能

### 1. 手机号登录
- 支持手机号 + 验证码登录
- 自动判断新用户注册或老用户登录
- 验证码倒计时功能
- 登录状态持久化存储

### 2. 用户信息管理
- 头像上传和修改
- 昵称修改
- 用户等级和积分显示
- 退出登录功能

### 3. 权限控制
- 未登录时只显示登录入口
- 登录后才显示功能模块
- 登录状态实时同步

## 测试说明

### 验证码规则（测试环境）
- 发送验证码后，使用以"1"开头的6位数字作为验证码
- 例如：123456、111111、100000 等
- 实际生产环境需要接入真实的短信服务

### 测试流程
1. 打开"我的"页面
2. 点击"手机号登录"
3. 输入有效的手机号（11位，1开头）
4. 点击"发送验证码"
5. 输入以"1"开头的6位验证码
6. 点击"确认登录"
7. 登录成功后可以修改头像、昵称等信息

## 云函数

### login 云函数
支持以下操作类型：
- `phoneLogin`: 手机号登录
- `updateProfile`: 更新用户信息
- `getUserInfo`: 获取用户信息

## 注意事项
1. 需要在微信开发者工具中开启云开发功能
2. 需要部署 login 云函数
3. 头像上传需要云存储权限
4. 生产环境需要配置真实的短信验证码服务
